# Sentri by Open Coding Society

Sentri is the Open Coding Society (OCS) GitHub Pages platform for Computer Science learning, classroom publishing, and student-led project development.

## Mission

Sentri and Open Coding Society work together as one learning ecosystem: OCS provides the instructional vision, and Sentri provides the web platform where lessons, projects, and reflections are published.

## What Sentri Includes

- CSP and CSA learning pathways
- Student project pages, hacks, and capstone artifacts
- Notebook-based and markdown-based lessons
- Shared UI includes, templates, and data-driven navigation
- Media assets for interactive modules and instructional content

## Repository Structure

- `_posts/` – dated blog posts and capstone writeups
- `_notebooks/` – lesson notebooks and coding activities
- `_includes/` – reusable site components
- `_data/` – navigation and metadata configuration
- `hacks/` – challenge modules and project-based lessons
- `images/` – visual assets used across the site
- `scripts/` – local automation and maintenance utilities

## GitHub Pages Setup

To publish Sentri on GitHub:

1. Open repository **Settings → Pages**.
2. Set deployment to **GitHub Actions**.
3. Confirm `_config.yml` uses the correct `baseurl` for your repository name.
